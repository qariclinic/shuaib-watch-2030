# اسلامک شعیب ڈیجیٹل واچ — 2030 ایڈیشن
تیار کردہ: مفتی حافظ محمد شعیب خان آلائی

## APK بنانے کا طریقہ
1. `unzip shuaib-watch-2030.zip && cd shuaib-watch-2030`
2. اپنی اذان کی آواز `www/audio/adhan.mp3` نام سے رکھیں (اس کے بغیر بیپ بجے گا)
3. GitHub پر خالی repo بنائیں، پھر: `./push.sh https://github.com/USERNAME/REPO.git`
4. GitHub > Actions > Build APK مکمل ہونے پر Artifacts سے `app-debug.apk` لیں

## خصوصیات
شمسی/ہجری تاریخ، اینالاگ+ڈیجیٹل گھڑی پر نماز کے نشان، اذان بوقتِ نماز، موسم (°F)، الارم، چلتی پٹی، عیدین/رمضان/عرفہ/عاشوراء/شبِ برأت و معراج/ایامِ بیض نمایاں۔
نماز کے اوقات: Aladhan API (حنفی، University of Islamic Sciences Karachi) — آف لائن میں آخری محفوظ اوقات۔
